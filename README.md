# [Bài tập] Tạo bảng nâng cao

## 1. Mục tiêu

Luyện tập sử dụng HTML và CSS để xây dựng, định dạng bảng:

- Sử dụng các thẻ `<table>`, `<tr>`, `<th>`, `<td>`.
- Sử dụng các thuộc tính cơ bản của bảng.
- Áp dụng CSS để tùy chỉnh giao diện bảng.

## 2. Nội dung bài tập

### Phần 1: Tạo bàn cờ vua

- Xây dựng bàn cờ vua gồm 8 hàng và 8 cột bằng bảng HTML.
- Sử dụng CSS để tạo các ô đen trắng xen kẽ.
- Hiển thị số hàng và ký hiệu cột theo mẫu.

### Phần 2: Tạo lịch tháng

- Xây dựng bảng lịch của một tháng bằng HTML.
- Hiển thị các ngày trong tuần và ngày trong tháng.
- Sử dụng CSS để định dạng màu sắc, đường viền và căn chỉnh nội dung.
- Thiết kế giao diện theo hình mẫu của đề bài.

## 3. Công nghệ sử dụng

- **HTML5:** Xây dựng cấu trúc bảng.
- **CSS3:** Thiết kế và định dạng giao diện.
- **Git/GitHub:** Quản lý và lưu trữ mã nguồn.

## 4. Yêu cầu hoàn thành

- Hoàn thiện bàn cờ vua và lịch tháng theo mẫu.
- Đưa toàn bộ mã nguồn lên GitHub.
- Nộp đường dẫn repository để giảng viên đánh giá.

## 5. Kết quả đạt được

- Hiểu và sử dụng được các thẻ HTML tạo bảng.
- Biết cách bố trí hàng, cột và các ô dữ liệu.
- Áp dụng CSS để xây dựng giao diện bảng trực quan.
- Rèn luyện kỹ năng tổ chức mã nguồn và sử dụng GitHub.
